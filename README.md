# Wings of Fire — LAN edition

Скопировано из [lana228-glitch/wings-of-fire](https://github.com/lana228-glitch/wings-of-fire). Исходная версия сохранена как `Qwen_html_20261010_w6p7ub4fi.html`, а рабочая оптимизированная страница — `index.html`.

## Как запустить без установки библиотек

Нужен только Python 3.9+.

```bash
python server.py
```

Сервер по умолчанию слушает **0.0.0.0:8000** (все сетевые интерфейсы), а не только localhost. В терминале появятся два адреса:

- На компьютере с сервером: **http://localhost:8000/**
- На других устройствах в той же Wi-Fi/LAN сети: **http://IP_КОМПЬЮТЕРА:8000/**

Например, если адрес компьютера `192.168.1.25`, откройте **http://192.168.1.25:8000/**.

Если подключение не работает, убедитесь, что устройства находятся в одной сети, в Windows Firewall/ufw разрешены входящие TCP-соединения на порт 8000 и точка доступа не включает client isolation (изоляцию клиентов). Не нужно перенаправлять порт роутера во внешний интернет.

```bash
python server.py --port 3000
python server.py --no-browser
python server.py --host 127.0.0.1  # только для своего компьютера
```

## Что изменилось

- Главная страница `/` сразу открывает игру, а не листинг папки или 404.
- Несколько клиентов одной сети видят положение, ориентацию и имя драконов друг друга (HTTP state relay, ~8 обновлений в секунду). На экране показывается число игроков; отключившиеся исчезают. До 32 одновременных клиентов.
- Мир и PvE (враги, урон, добыча, очки) **пока остаются локальными для каждого клиента**, общий бой/общая экономика не синхронизируются. Эта версия добавляет совместное присутствие, а не полноценный серверный PvE.
- Высоты рельефа на сетке кэшируются; буферы проекции воды переиспользуются.
- При низкой частоте кадров постепенно уменьшаются детализация дальнего рельефа и разрешение canvas; когда FPS восстанавливается — качество возвращается.
- Сервер кэширует статические файлы в памяти, отдаёт gzip и поддерживает ETag/304. HTML всегда перепроверяется браузером, чтобы обновления игры не застревали в кэше.
- Только Python из стандартной библиотеки, без Node.js/npm.

## Структура

- `index.html` — запускаемая игра + оптимизация и сетевой слой.
- `Qwen_html_20261010_w6p7ub4fi.html` — оригинальная игра из исходного репозитория, сохранена без изменений.
- `server.py` — HTTP LAN-сервер и API `POST /api/state`.
- `src/js/` — исходные JS-модули, сохранённые из первоисточника.
- `scripts/` — исходные инструменты извлечения и экспериментальной модульной сборки.
- `tests/` — тесты HTTP и сетевого API.

Запустить проверки: `python -m unittest discover -s tests -v`.
